* **دانلود منیجر و تورنت:** دانلود موازی چندرشته‌ای فایل‌ها و پشتیبانی از مگنت و تورنت.
* **فشرده‌ساز Omni Archive:** فشرده‌سازی با الگوریتم امنیتی `.omni` و پشتیبانی از استخراج ZIP.

* **گالری و گیف:** نمایش تصاویر و فایل‌های متحرک GIF با زوم روان ماوس.
* **پی‌دی‌اف استودیو:** مطالعه اسناد، هایلایت، قرار دادن یادداشت‌های متحرک و پرینت مستقیم.
